# Фото для блока «Обо мне»

Положите сюда файл **`anton.jpg`**.

- Кадр: портрет, соотношение **4:5** (например 900×1125), от 900 px по ширине.
- Рекомендуемый снимок из трёх присланных — **тёмный коридор, фигура у чёрной стены**:
  в нём уже есть вертикали и жёсткая геометрия, он ложится на графитовую палитру
  без доработок.
- Тонировать вручную не нужно: страница сама переводит фото в чёрно-белое
  (`grayscale`) и накладывает поверх едва заметную сетку — фото становится частью чертежа.
- Кадрирование по вертикали задано в CSS: `object-position: 50% 22%` (лицо в верхней трети).
  Если голова обрезается — поправьте это значение в `landing/static/landing/css/site.css`.

Пока файла нет, на его месте показывается аккуратная заглушка «ФОТО 4:5» —
вёрстка не ломается.
